## 🎯 Motivation

This handbook was built to help students compile and review university laboratory experiments in one place, providing a reliable reference for fast revision and output cross-checking right before final practical exams.

---

## ⚡ Key Features

* 📋 **One-Click Code Copy**: Instantly copy code blocks to clipboard for local testing.
* 📊 **Verifiable Output Logs**: Expected terminal outputs are embedded next to code logs for quick verification.
* 💬 **Viva Study Cards**: Collapsible conceptual questions at the bottom of each experiment for quick oral prep.
* 📱 **Mobile-Optimized**: Light and responsive page structures tailored for fast reading on phones.
